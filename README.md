# Wiki Search

Консольная программа для поиска в Википедии (практическое задание 2, ООП).

Пользователь вводит запрос, программа показывает до 10 найденных статей,
после выбора номера открывает статью в браузере.

## Требования
- JDK 17+
- Maven 3.8+ (зависимость Gson подтянется автоматически)

## Запуск
```
mvn -q compile exec:java
```
Или сборка jar: `mvn package`, затем `java -jar target/wiki-search-1.0.jar`
(для запуска jar нужен classpath с Gson - проще использовать `exec:java`).

> Если русский текст в консоли Windows отображается некорректно, выполните `chcp 65001`
> и запускайте с `-Dstdout.encoding=UTF-8 -Dstdin.encoding=UTF-8`.

## Структура
| Класс | Ответственность |
|-------|-----------------|
| `Main` | точка входа |
| `App` | основной цикл, связывает компоненты |
| `ConsoleInput` | чтение запроса и выбора статьи |
| `WikipediaClient` | HTTP-запрос к API, URL-кодирование |
| `SearchResponseParser` | разбор JSON (Gson) в `SearchResult` |
| `SearchResult` | модель найденной статьи, ссылка по `pageid` |
| `ResultPrinter` | вывод результатов и сообщений |
| `ArticleOpener` | открытие статьи в браузере (`Desktop`) |
| `WikipediaApiException` | ошибки сети/API/разбора |

## Обработка ошибок
Пустой запрос, ошибки сети и HTTP, некорректный JSON, отсутствие результатов,
нечисловой или выходящий за диапазон выбор - программа сообщает о проблеме и продолжает работу.
